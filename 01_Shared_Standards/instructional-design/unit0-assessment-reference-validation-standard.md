# Unit 0 Assessment Reference Validation Standard

## Purpose
Define the synthetic, noncanonical Unit 0 integration-validation contract for #842. It proves that the current assessment stack composes across one realistic Digital Media Studio Foundations-shaped scenario without creating approved curriculum targets, production assessments, classroom materials, or external writes.

## Upstream Boundary
This contract consumes #837 assessment-design semantics, #838 blueprint structure, #1192 lifecycle/change-impact/stale-validation evidence, #839 sequencing/student-experience evidence, #841 QA evidence, and #843 dashboard/workspace evidence by reference.

It does not redefine those contracts. Teacher-facing behavior consumes Teacher Decision Studio and Artifact-First Response by reference. #840 remains retired and is not an active dependency.

## Synthetic Fixture Rule
Every Unit 0 fixture is explicitly `synthetic_noncanonical`. Synthetic target identifiers and scenario names are regression identities only. They are not approved learning targets, canonical Unit 0 content, production assessments, or classroom artifacts.

## Integrated Validation Requirements
A valid synthetic integration case must preserve all of the following:
- survey evidence remains `survey_only` and cannot establish mastery;
- procedural and technical-workflow claims use authentic performance/process evidence when required by #837;
- observation cases contain observable evidence and bounded scoring/observation guidance;
- critique evidence remains target/claim aligned;
- AI-policy conditions are assignment-specific and are not inferred as universal rules;
- vocabulary application is used only after supplied synthetic instruction/practice evidence;
- #1192 owns stale state, bounded invalidation, preserved-object identity, and revalidation scope;
- #839 owns sequencing, language, cognitive demand, accessibility, engagement, time, and workload findings;
- #841 QA remains report-only and non-authorizing;
- #843 owns dashboard-first presentation, nonlinear section editing, warning-to-repair, progressive disclosure, and unrelated-work preservation;
- technical/audit detail is optional rather than a prerequisite for useful teacher action;
- fixed authority remains false for execution, classroom use, grading, readiness, production, publication, external writes, and source-of-truth writes.

## Positive Coverage
The minimum positive fixture set covers:
- readiness survey separated from mastery;
- file/folder organization as authentic performance evidence;
- equipment inspection as observable evidence;
- constructive critique with target/claim/evidence alignment;
- assignment-specific AI judgment;
- vocabulary application after explicit practice;
- a local section revision that preserves unrelated current sections;
- warning-to-repair linkage and optional technical detail;
- fixed false authority throughout the integrated evidence chain.

## Negative Coverage
Fail the integration case when any supplied evidence indicates:
- confidence or perceived readiness is treated as mastery;
- a procedural/technical claim relies only on selected response when authentic evidence is required;
- target, claim, evidence, or method is unsupported or mismatched;
- vocabulary is used without supplied instruction/practice eligibility;
- supplied #839 evidence reports invalid sequencing, excessive construct-irrelevant demand, or unresolved workload/accessibility failure;
- required scoring/observation guidance or instructional usefulness is missing;
- assignment-specific AI policy conflicts with the case;
- #1192 reports stale/ambiguous state that is presented as current;
- a bounded local revision resets unrelated valid sections;
- a #843 warning lacks a repair route or technical detail precedes usable content;
- QA, dashboard status, or any other validation evidence elevates authority.

## Deterministic Integration Result
Return `valid` only when every required upstream signal is current, compatible, synthetic/noncanonical, and authority-safe. Any violated hard boundary returns `invalid`. This integration result does not replace any upstream disposition; it only verifies composition.

## Defect Routing
A failure routes back to the owning contract rather than being repaired by redefining semantics here:
- assessment-design mismatch -> #837;
- blueprint structure -> #838;
- stale/change-impact/preservation -> #1192;
- sequencing/student experience -> #839;
- QA finding/disposition -> #841;
- dashboard/workspace behavior -> #843.

#846 may consume accepted synthetic Unit 0 regression evidence for portability testing, but Unit 0 fixture content must not become a universal cross-unit rule.

## Authority and Non-Goals
All #842 evidence is test/reference evidence only. No fixture or integration result authorizes classroom use, grading, readiness, production, publication, external writes, source-of-truth mutation, workflow/protected-setting change, credentials, persistence, a production UI, or a standalone Assessment Agent.
