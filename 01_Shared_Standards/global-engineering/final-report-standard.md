# Final Report Standard

Final-report field ownership and visible presentation are canonical in
`agent-interaction-output-standard.md`.

Use its base evidence contract for files changed, tests run, docs updated,
unresolved blockers, handoff recommendations, and remaining risks. Add
issue- or domain-specific evidence only when the governing contract requires it.

This document is a compatibility pointer and must not define a competing output
schema or presentation order.
