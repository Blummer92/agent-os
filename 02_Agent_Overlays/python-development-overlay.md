# Python Development Overlay
## Status
Legacy compatibility guidance; not a canonical executable agent or repository
implementation owner.

## Purpose
Preserve historical Python-specific routing language while directing current
repository implementation to the GitHub Service Agent and current Python
engineering rules to `01_Shared_Standards/python/`.

## Resolution
When older prompts, tests, or documentation refer to the Python Development
Overlay as an implementation role:

1. resolve repository implementation ownership to GitHub Service Agent;
2. apply the relevant standards under `01_Shared_Standards/python/`;
3. retain QA / Test Agent ownership of independent validation evidence; and
4. retain external-system owners for domain requirements and separately
   authorized external writes.

Programming language alone never selects an executable agent.

## Blocked Authority
This compatibility overlay grants no Notion, Drive, Sheets, Workspace,
production, credential, protected-setting, or other external-write authority and
does not create a second GitHub repository writer.
