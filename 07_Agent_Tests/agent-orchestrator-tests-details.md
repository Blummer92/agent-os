# Agent Orchestrator Test Details

Supplementary deterministic interaction fixtures. This file does not define a second overlay or runtime contract.

## #1213 Confirmation Matrix

- explicit acceptance of one clear proposal confirms that proposal only;
- ambiguous assent after multiple consequential proposals is unresolved (`multiple-proposal assent`);
- a follow-up question is not confirmation;
- partial or modified acceptance confirms only the accepted/modified choice;
- rejection, later correction, or custom choice preserves unrelated planning.

## #1213 Conversation / Choice Matrix

Cover a vague teacher, expert complete request, rushed teacher, one-word mobile reply, rejected recommendation, one strong route, two valid routes, custom option, alignment-breaking preference, and controlling blocker. Routine turns remain compact and normally ask zero or one material question.

## #1213 Context Matrix

Cover exact current context, stale context, conflicting context, ambiguous identity, previous-year/archived context, and explicit `start fresh`. Supplied canonical currentness outcomes are presentation inputs; these fixtures do not retest or replace currentness algorithms.

## #1213 Golden Conversations

- **Color** — sparse idea; do useful backward-design work before the first material question.
- **AI Movie Poster** — project-first planning; teacher choice, disagreement, and reversal remain easy and non-punitive.
- **Photography** — strong current context is reused naturally; do not repeat questions already answered by approved context.
- **Roller Coaster** — a genuine source/production controlling blocker stays visible while safe exploratory planning remains clearly non-authorizing.

## #1214 Cross-owner Integration Matrix

- **AI Movie Poster** — reuse current context, preserve teacher choice and reversal, trigger the bounded advisory only for a material visibility/teachability concern, then require formal Unit Alignment PASS before full Teacher Modeling.
- **Photography** — existing adequate modeling/context suppresses unnecessary advisory; source restrictions survive every downstream view.
- **Typography** — invisible comparison/reasoning may trigger `full modeling needs attention later` or a narrow structural concern without changing unit intent.
- **AI Superhero** — evaluation/revision thinking may trigger the advisory; optional extensions remain optional and AI use alone is not a trigger.
- **Roller Coaster** — source/modeling/production blockers remain controlling; exploratory planning never converts them into readiness.

Adversarial integration must prove: Unit Sketch acceptance cannot set Unit Alignment PASS; a pre-PASS advisory cannot set Modeling READY/BLOCKED; advisory output cannot mutate Unit Alignment-owned intent or serve as formal Teacher Modeling verification; full Teacher Modeling cannot start before canonical Unit Alignment PASS; Materials cannot consume advisory output as approved modeling or guess unresolved teacher intent; missing required formal modeling remains blocking; existing adequate modeling suppresses unnecessary advisory; a structural concern returns only the affected concern to Unit Alignment without ping-pong/full restart; changed material inputs invalidate affected stale PASS/READY assumptions; current canonical evidence outranks chat memory; source/owner conflicts remain visible; complex rubric/assessment tradeoffs use Teacher Decision Studio while simple choices do not; teacher custom/rejected choices remain valid unless canonically invalid; and no new state, memory, freshness, readiness, packet, router, lifecycle, or external-write dependency is introduced.

## Mobile Acceptance

The golden/decision fixtures must remain readable on a phone: compact routine turn, zero/one material question, no wide comparison table for a two-option choice, scannable `Your decisions / Still open / Next` checkpoint, and blocker visibility without opening audit detail.
