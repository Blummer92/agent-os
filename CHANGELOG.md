- BUGSQUASH-1B (#1273) — Acceptance-report evidence completeness now fails closed at the workflow boundary instead of silently degrading. The report workflow reconciles GitHub's authoritative `changedFiles` count against the retrieved file list and emits an explicit incompleteness signal on mismatch, records `gh pr diff` retrieval failure instead of swallowing it with `|| true`, and reuses one `LinkedIssueParseStatus.RESOLVED`-gated linked-issue extraction for issue retrieval and transport binding. The acceptance CLI accepts the two bounded evidence-completeness flags and converts either condition into `manual-review` evidence without changing report schema or widening workflow permissions. Regression coverage includes simulated truncated changed-file evidence, diff retrieval failure, matched-count unchanged behavior, and the single status-gated linked-issue extraction contract. No other workflow, permissions, protected settings, Cloud Build/GCE, production, merge, issue closure, or external-system write is included.
